## Share Note

<api-endpoint>
  POST /api/notes/shared-statuses
</api-endpoint>

Share a note with another user and set their permission level (View or Edit).

### Headers

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication
</ParamField>

### Body Parameters

<ParamField body="notes_id" type="string" required>
  The ID of the note to share
</ParamField>

<ParamField body="sharedWith" type="object" required>
  User object to share the note with
  
  <ParamField body="sharedWith.id" type="number" required>
    ID of the user to share with
  </ParamField>
</ParamField>

<ParamField body="permissions" type="string" required>
  Permission level for the shared user. Must be either `View` or `Edit`
</ParamField>

### Response

<ResponseField name="message" type="string">
  Success message
</ResponseField>

<ResponseField name="data" type="object">
  The created shared status object
  
  <ResponseField name="data.id" type="number">
    Unique identifier for the shared status
  </ResponseField>
  
  <ResponseField name="data.sharedById" type="number">
    ID of the user who shared the note
  </ResponseField>
  
  <ResponseField name="data.sharedWithId" type="number">
    ID of the user who received the share
  </ResponseField>
  
  <ResponseField name="data.noteId" type="number">
    ID of the shared note
  </ResponseField>
  
  <ResponseField name="data.permissions" type="string">
    Permission level: "View" or "Edit"
  </ResponseField>
  
  <ResponseField name="data.sharedAt" type="string">
    Timestamp when the note was shared
  </ResponseField>
</ResponseField>

<CodeGroup>
```bash View Permission
curl -X POST https://api.noteverse.com/api/notes/shared-statuses \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "notes_id": "123",
    "sharedWith": {
      "id": 42
    },
    "permissions": "View"
  }'
```

```bash Edit Permission
curl -X POST https://api.noteverse.com/api/notes/shared-statuses \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "notes_id": "123",
    "sharedWith": {
      "id": 42
    },
    "permissions": "Edit"
  }'
```

```javascript JavaScript
const response = await fetch(
  'https://api.noteverse.com/api/notes/shared-statuses',
  {
    method: 'POST',
    headers: {
      'Authorization': 'Bearer YOUR_TOKEN',
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      notes_id: '123',
      sharedWith: { id: 42 },
      permissions: 'View'
    })
  }
);
const data = await response.json();
```
</CodeGroup>

### Response Example

```json
{
  "message": "Shared statuses fetched successfully",
  "data": {
    "id": 789,
    "sharedById": 1,
    "sharedWithId": 42,
    "noteId": 123,
    "permissions": "View",
    "sharedAt": "2026-03-03T10:30:00.000Z"
  }
}
```

<Note>
  The authenticated user (from the Authorization header) is automatically set as the `sharedById` user.
</Note>

### Error Responses

**400 Bad Request** - Missing note ID
```json
{
  "error": "Note id is required",
  "statusCode": 400
}
```

**400 Bad Request** - Authentication failure
```json
{
  "error": "Error fetching shared statuses",
  "statusCode": 400
}
```

## Get Shared Statuses

<api-endpoint>
  GET /api/notes/shared-statuses
</api-endpoint>

Retrieve all sharing information for a specific note, including who has access and their permission levels.

### Headers

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication
</ParamField>

### Query Parameters

<ParamField query="notes_id" type="string" required>
  The ID of the note to get sharing information for
</ParamField>

### Response

<ResponseField name="message" type="string">
  Success message
</ResponseField>

<ResponseField name="data" type="array">
  Array of shared status objects
  
  <ResponseField name="data[].id" type="number">
    Shared status ID
  </ResponseField>
  
  <ResponseField name="data[].noteId" type="number">
    The note ID
  </ResponseField>
  
  <ResponseField name="data[].permissions" type="string">
    Permission level: "View" or "Edit"
  </ResponseField>
  
  <ResponseField name="data[].sharedBy" type="object">
    User who shared the note
    
    <ResponseField name="data[].sharedBy.id" type="number">
      User ID
    </ResponseField>
    
    <ResponseField name="data[].sharedBy.email" type="string">
      User email
    </ResponseField>
    
    <ResponseField name="data[].sharedBy.username" type="string">
      Username
    </ResponseField>
  </ResponseField>
  
  <ResponseField name="data[].sharedWith" type="object">
    User who received the share
    
    <ResponseField name="data[].sharedWith.id" type="number">
      User ID
    </ResponseField>
    
    <ResponseField name="data[].sharedWith.email" type="string">
      User email
    </ResponseField>
    
    <ResponseField name="data[].sharedWith.username" type="string">
      Username
    </ResponseField>
  </ResponseField>
</ResponseField>

</ParamField>

## Delete Shared Status

<api-endpoint>
  DELETE /api/notes/shared-statuses
</api-endpoint>

Remove sharing access for a user by deleting the shared status.

### Headers

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication
</ParamField>

### Query Parameters

<ParamField query="status_id" type="string" required>
  The ID of the shared status to delete
</ParamField>

### Response

<ResponseField name="message" type="string">
  Success message
</ResponseField>

<ResponseField name="data" type="object">
  Deleted shared status object
</ResponseField>

<CodeGroup>
```bash cURL
curl -X DELETE "https://api.noteverse.com/api/notes/shared-statuses?status_id=789" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</CodeGroup>

### Response Example

```json
{
  "message": "Shared statuses deleted successfully",
  "data": {
    "id": 789,
    "sharedById": 1,
    "sharedWithId": 42,
    "noteId": 123,
    "permissions": "View",
    "sharedAt": "2026-03-03T10:30:00.000Z"
  }
}
```

<Warning>
  Deleting a shared status immediately revokes the user's access to the note. This action cannot be undone.
</Warning>

## Permission Types

The sharing system supports two permission levels defined in the Prisma schema:

- **View**: User can only view the note content
- **Edit**: User can view and modify the note content

These permissions are enforced as an enum type in the database schema.
