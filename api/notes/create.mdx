---
title: "Create Note"
api: "POST /api/notes"
description: "Create a new note owned by the authenticated user"
---

## Authentication

This endpoint requires authentication via an Authorization header.

<ParamField header="Authorization" type="string" required>
  Bearer token for user authentication
</ParamField>

## Request Body

<ParamField body="title" type="string" required>
  The title of the note to be created
</ParamField>

## Response

<ResponseField name="message" type="string">
  Success message indicating the note was created
</ResponseField>

<ResponseField name="data" type="object">
  The created note object
  
  <ResponseField name="id" type="number">
    Unique identifier for the note
  </ResponseField>
  
  <ResponseField name="title" type="string">
    Title of the note
  </ResponseField>
  
  <ResponseField name="data" type="string | null">
    Content of the note (null when first created)
  </ResponseField>
  
  <ResponseField name="description" type="string | null">
    Description of the note
  </ResponseField>
  
  <ResponseField name="thumbnail" type="string | null">
    Thumbnail image path
  </ResponseField>
  
  <ResponseField name="views" type="number">
    Number of views (defaults to 0)
  </ResponseField>
  
  <ResponseField name="visibility" type="string">
    Note visibility: "Public", "Private", or "Shared" (defaults to "Private")
  </ResponseField>
  
  <ResponseField name="ownerId" type="number">
    ID of the user who owns the note
  </ResponseField>
  
  <ResponseField name="createdAt" type="string">
    ISO 8601 timestamp when the note was created
  </ResponseField>
  
  <ResponseField name="updatedAt" type="string">
    ISO 8601 timestamp when the note was last updated
  </ResponseField>
</ResponseField>

<CodeGroup>
```bash cURL
curl -X POST https://api.noteverse.com/api/notes \
  -H "Authorization: Bearer YOUR_AUTH_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "My First Note"
  }'
```

```javascript JavaScript
const response = await fetch('https://api.noteverse.com/api/notes', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer YOUR_AUTH_TOKEN',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    title: 'My First Note'
  })
});

const data = await response.json();
```

```python Python
import requests

response = requests.post(
    'https://api.noteverse.com/api/notes',
    headers={
        'Authorization': 'Bearer YOUR_AUTH_TOKEN',
        'Content-Type': 'application/json'
    },
    json={
        'title': 'My First Note'
    }
)

data = response.json()
```
</CodeGroup>

## Error Responses

<ResponseField name="error" type="string">
  Error message describing what went wrong
</ResponseField>

### Unauthorized (401)

Returned when the authentication token is invalid or missing.

```json
{
  "error": "Invalid or expired token"
}
```

### Bad Request (400)

Returned when the request is malformed or validation fails.

```json
{
  "error": "Error creating note"
}
```

<Note>
The note is created with default visibility set to "Private". You can change this using the [publish endpoint](/api/notes/publish).
</Note>
