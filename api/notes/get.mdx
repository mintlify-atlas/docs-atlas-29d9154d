---
title: "Get Notes"
api: "GET /api/notes"
description: "Retrieve notes based on query parameters - user's own notes, a specific note, shared notes, or public notes"
---

## Authentication

This endpoint requires authentication via an Authorization header.

<ParamField header="Authorization" type="string" required>
  Bearer token for user authentication
</ParamField>

## Query Parameters

<ParamField query="id" type="string" optional>
  Retrieve a specific note by ID. The user must be the owner, have the note shared with them, or the note must be public.
</ParamField>

<ParamField query="type" type="string" optional>
  Filter notes by type:
  - `shared` - Returns notes that have been shared with the authenticated user
  - `featured` - Returns all public notes
  
  If neither `id` nor `type` is provided, returns all notes owned by the authenticated user.
</ParamField>

## Response

<ResponseField name="message" type="string">
  Success message indicating notes were fetched successfully
</ResponseField>

<ResponseField name="data" type="array | object">
  Array of note objects (or single note object when querying by `id`)
  
  <ResponseField name="id" type="number">
    Unique identifier for the note
  </ResponseField>
  
  <ResponseField name="title" type="string">
    Title of the note
  </ResponseField>
  
  <ResponseField name="data" type="string | null">
    Content of the note
  </ResponseField>
  
  <ResponseField name="description" type="string | null">
    Description of the note
  </ResponseField>
  
  <ResponseField name="thumbnail" type="string | null">
    Thumbnail image path
  </ResponseField>
  
  <ResponseField name="views" type="number">
    Number of views
  </ResponseField>
  
  <ResponseField name="visibility" type="string">
    Note visibility: "Public", "Private", or "Shared"
  </ResponseField>
  
  <ResponseField name="ownerId" type="number">
    ID of the user who owns the note
  </ResponseField>
  
  <ResponseField name="createdAt" type="string">
    ISO 8601 timestamp when the note was created
  </ResponseField>
  
  <ResponseField name="updatedAt" type="string">
    ISO 8601 timestamp when the note was last updated
  </ResponseField>
  
  <ResponseField name="owner" type="object">
    Owner information
    
    <ResponseField name="id" type="number">
      User ID
    </ResponseField>
    
    <ResponseField name="email" type="string">
      User email
    </ResponseField>
    
    <ResponseField name="username" type="string">
      Username
    </ResponseField>
  </ResponseField>
  
  <ResponseField name="sharedStatuses" type="array">
    Array of sharing information
    
    <ResponseField name="id" type="number">
      Sharing record ID
    </ResponseField>
    
    <ResponseField name="sharedById" type="number">
      ID of user who shared the note
    </ResponseField>
    
    <ResponseField name="sharedWithId" type="number">
      ID of user the note was shared with
    </ResponseField>
    
    <ResponseField name="permissions" type="string">
      Permission level: "View" or "Edit"
    </ResponseField>
    
    <ResponseField name="noteId" type="number">
      ID of the shared note
    </ResponseField>
    
    <ResponseField name="sharedAt" type="string">
      ISO 8601 timestamp when the note was shared
    </ResponseField>
  </ResponseField>
  
  <ResponseField name="likes" type="array">
    Array of users who liked the note (returned for owned notes, shared notes, and featured notes)
  </ResponseField>
  
  <ResponseField name="comments" type="array">
    Array of comments on the note (returned for shared and featured notes)
  </ResponseField>
</ResponseField>

<CodeGroup>
```bash Get User's Notes
curl -X GET https://api.noteverse.com/api/notes \
  -H "Authorization: Bearer YOUR_AUTH_TOKEN"
```

```bash Get Specific Note
curl -X GET "https://api.noteverse.com/api/notes?id=123" \
  -H "Authorization: Bearer YOUR_AUTH_TOKEN"
```

```bash Get Shared Notes
curl -X GET "https://api.noteverse.com/api/notes?type=shared" \
  -H "Authorization: Bearer YOUR_AUTH_TOKEN"
```

```bash Get Featured Notes
curl -X GET "https://api.noteverse.com/api/notes?type=featured" \
  -H "Authorization: Bearer YOUR_AUTH_TOKEN"
```

## Error Responses

### Unauthorized (401)

Returned when the authentication token is invalid or missing.

```json
{
  "error": "Invalid or expired token"
}
```

### Not Found (404)

Returned when the requested note(s) cannot be found.

```json
{
  "error": "Notes not found"
}
```

<Note>
When querying a specific note by `id`, the user must either:
- Own the note
- Have the note shared with them
- The note must have "Public" visibility
</Note>

<Warning>
The `type=featured` query returns all public notes in the system, which may be a large dataset. Consider implementing pagination for production use.
</Warning>
