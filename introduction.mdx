## What is Noteverse?

Noteverse is a modern, real-time collaborative note-sharing platform that enables you to create, share, and edit notes collaboratively while engaging through social features. Built with Next.js and powered by Novel.sh's rich text editor, Noteverse transforms note-taking into a collaborative and social experience.

## Key features

<AccordionGroup>
  <Accordion icon="users" title="Real-time collaboration">
    Edit notes simultaneously with other users using Socket.IO for instant synchronization. See changes as they happen and collaborate seamlessly with your team.
  </Accordion>

  <Accordion icon="pen-fancy" title="Rich text editor">
    Powered by TipTap and Novel.sh, enjoy a Notion-style WYSIWYG editing experience with support for formatting, embeds, and more.
  </Accordion>

  <Accordion icon="heart" title="Social engagement">
    Like, upvote, and reward valuable notes. Build a community around knowledge sharing with integrated social features.
  </Accordion>

  <Accordion icon="comments" title="Comments and discussions">
    Engage in meaningful discussions with nested comments and replies. Foster collaboration through threaded conversations.
  </Accordion>

  <Accordion icon="share-nodes" title="Flexible sharing">

    Built-in theme switching with next-themes. Seamlessly transition between light and dark modes.
  </Accordion>

## Built with modern technology

Noteverse leverages cutting-edge technologies to deliver a fast, reliable, and delightful user experience:

- **Next.js 14** - React framework for production with server-side rendering
- **TypeScript** - Type-safe development for fewer bugs
- **Prisma** - Type-safe database ORM with PostgreSQL
- **Socket.IO** - Real-time bidirectional communication
- **NextAuth.js** - Secure authentication with support for OAuth providers
- **Tailwind CSS** - Utility-first styling for rapid UI development
- **Novel.sh** - Notion-style WYSIWYG editor built on TipTap

<Note>
  Noteverse is optimized to work with Bun as the package manager for the best development experience.
</Note>
